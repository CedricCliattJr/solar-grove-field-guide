Printable sheets for the terminal, written in plain language. Pin them near the machine; annotate freely.

Two sheets so far. The first is what you need to move around a Linux machine at all; the second is what you need once you're running things on it. Every command is one you'll actually type, described in the words you'd use to explain it to someone standing next to you.
