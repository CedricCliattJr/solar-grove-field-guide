Second Season

Version control, containers, and the diagnostics of a working homelab. Specimens gathered in the field, July 2026.

Git — the daily loop

  1. Edit your files as normal.
  2. git status — see what changed.
  3. git add . — stage everything.
  4. git commit -m "message" — snapshot it.
  5. git push — send it to the server.

Those five, in that order, forever. Everything else is detail.

Git — setup & history

git init -b main
Start tracking this folder. -b main names the first branch.
git remote add name url
Point at a server. origin is the conventional name for your main one.
git remote -v
List every remote you've added, and where each points.
git push -u origin main
First push. -u remembers the target so later pushes are just git push.
git log --oneline
Your history, one commit per line.
git diff
Exactly what changed since the last commit.
git checkout .
The undo. Throws away uncommitted changes, back to last commit.
git clone url
Copy a repo down from a server.
git pull
Fetch changes made elsewhere into this copy.
.gitignore
A file listing what git should ignore. One pattern per line — e.g. *.backup

Two remotes, one repo

git remote add gitea url
Drafts and works-in-progress → your own server.
git remote add github url
Finished, portfolio-ready work → public.
git push gitea main
Send to one specifically. Same commits, your choice of destination.

Docker — reading a live stack

docker ps
Every running container, with ports and health.
docker ps --format "{{.Names}}"
Just the names. Useful when the full table is unreadable.
docker logs name --tail 30
Last 30 log lines. Where a broken container confesses.
docker restart name
Also stop / start for one at a time.
docker exec name cmd
Run a command inside a container.
docker exec -it name sh
Open a shell inside it and look around. exit to leave.
docker inspect name
Everything about it. Pair with --format to pull one field.
docker logs -f name
Follow logs live as they happen. Ctrl+C to stop.

Storage & filesystems

lsblk -o NAME,SIZE,UUID,MOUNTPOINT
Every drive, its identity, and where it's mounted. Start here.
df -h
What's mounted and how full. A missing line = a drive that fell off.
du -sh folder/*
Size of each item inside a folder.
cat /etc/fstab
The map of drive → folder at boot. Should use UUID=, not /dev/sdX.
blkid
Print UUIDs, for writing fstab entries.
sudo mount -a
Mount everything in fstab that isn't already mounted.
sudo umount /path
Unmount. Always do this before checking a filesystem.
sudo e2fsck -fy /dev/sdX1
Repair an ext4 filesystem. Unmounted only. Replays a dirty journal after a drive loses power.

When something breaks

sudo dmesg | tail -30
Kernel log. Hardware faults, I/O errors, drives disappearing.
sudo dmesg | grep -i error
Filter it to just the complaints.
journalctl -xe
Recent system logs with explanations.
journalctl -u service
Logs for one service specifically.
systemctl --failed
Everything that tried to start and didn't.

Writing & reading files

cat file
Read a file to the screen.
cat > file
Write — creates or overwrites. The > is the whole difference.
cat >> file
Append to the end instead of overwriting.
cat > f << 'EOF'
Write several lines at once. Type your content, then EOF alone on the last line.
echo "text" > file
Quick one-line file.
sed -n '10,20p' file
Print just lines 10–20. Good for inspecting one section.
head -20 · tail -30
First / last N lines.
cat -A file
Reveal invisible characters — stray line endings, odd whitespace.
wc -l file
Count lines.

Hardware inventory

sudo dmidecode -t memory
RAM: size, speed, form factor, and which slots are empty.
lscpu · free -h
Processor details · memory in use.
lsusb · lspci
Devices on USB · on the PCI bus. How you learn whether hardware exists at all.
rfkill list
Wireless radios present, and whether they're blocked.
file thing
What a file actually is, regardless of its extension.
nvidia-smi
GPU status. If this prints a table, your driver is working.

Sound

wpctl status
All audio devices. The * marks the active one.
wpctl set-default ID
Switch output, using an ID from the list above.
wpctl set-volume @DEFAULT_AUDIO_SINK@ 0.7
Set volume to 70%.
pavucontrol
The graphical mixer. Per-app volume and device switching — usually faster than the terminal.

Hyprland & desktop

hyprctl reload
Apply config changes without logging out.
hyprctl monitors
Resolution, refresh rate, and every mode your display supports.
hyprctl clients
Every open window and which workspace it's on. Finds "lost" windows.
require("conf.name")
In hyprland.lua — loads conf/name.lua. The dot is a path separator; drop the .lua.
grim -g "$(slurp)" - | wl-copy
Drag-select a screenshot straight to the clipboard.
grim -g "$(slurp)" out.png
Same, but saved to a file.
app & disown
Launch an app detached, so closing the terminal doesn't kill it.

Traps already sprung

monitors.lua not monitors/lua
A dot separates name from extension. A slash means folder. Mixing them gives "No such file or directory."
cat > file not cat file
Without the > you're reading, not writing — and it errors on a file that doesn't exist yet.
export TERM=xterm-256color
Run this after SSHing from kitty, or nano and htop refuse to draw: "Error opening terminal: xterm-kitty."
Ctrl+Shift+C / V
Copy and paste in a terminal. Plain Ctrl+C means "stop."
Drive letters move
/dev/sdb can become /dev/sde after a reboot or power loss. UUIDs never change — always use them in fstab.
nofail in fstab
Lets the machine boot when a drive is missing instead of dropping to emergency mode. Worth having on every non-essential mount.
One command per line
Pasting two commands onto one line silently mangles both. Wait for the prompt to return.
Containers talk by name
Two containers on the same Docker network reach each other as http://container-name:port — no IP needed.

The grove check

Thirty seconds, whenever you sit down. Tells you where you stand before you start guessing.

  1. df -h — are all drives still mounted?
  2. docker ps — is everything up and healthy?
  3. systemctl --failed — did anything die quietly?
  4. free -h — memory headroom still comfortable?

Reaching out

ssh user@host
A shell on another machine. exit to come home.
~/.ssh/config
Store hosts here and type ssh solargrove instead of the full address.
scp -r src user@host:/path
Copy files across. -r for folders.
curl -s url
Fetch a URL from the terminal. How you test an API without a browser.
curl -o /dev/null -w "%{http_code}\n" url
Print just the status code. 200 = working.
tailscale status
Who's on the tailnet. Local IPs work at home; Tailscale works anywhere.
