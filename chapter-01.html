Solar Grove · Field Notes № 01

A Field Guide to
the Command Line

Common specimens observed in the wild on EndeavourOS. Pin near the terminal; annotate freely.

Finding your footing

pwd
Where am I? Prints the current folder.
ls · ls -la
List what's here. -la shows hidden files and details.
cd folder
Walk into a folder.
cd .. · cd ~ · cd -
Up one level · home · back to the last place you stood.
/path vs path
A leading / starts from the root of the system. Without it, you start from where you are.

Tending files

cat file
Spill a file's contents onto the screen.
less file
Read a long file, scrollable. Press q to leave.
nano file
Edit. Save with Ctrl+O, Enter. Leave with Ctrl+X.
cp a b · cp -r a b
Copy. Add -r for whole folders.
mv a b
Move — and also how you rename.
rm file · rm -r folder
Delete. No recycle bin. Read twice, run once.
mkdir -p a/b
Make folders, parents included.

Power & session

systemctl suspend
Sleep. The one you were looking for.
systemctl poweroff
Shut down. shutdown now also works.
systemctl reboot
Restart.
systemctl hibernate
Sleep to disk. Needs swap configured.
exit
Close this shell or leave an SSH session.

Pacman & yay — software

sudo pacman -S pkg
Install from the official repositories.
sudo pacman -Syu
Refresh lists and upgrade everything. Do it often.
sudo pacman -R pkg
Remove. -Rns also clears unused dependencies.
pacman -Ss term
Search available packages.
pacman -Qs term
Search what's already installed.
yay -S pkg
Same, but reaches the AUR — community-built packages.

Services (systemd)

systemctl status name
Is it running? Why did it stop?
sudo systemctl start · stop
Run it now · halt it now.
sudo systemctl enable --now name
Start it and start it every boot from here on.
systemctl --user …
Same commands for things that belong to you, not the system.
journalctl -xe
Recent system logs. Where errors confess.

Surveying the machine

df -h
Free space per drive, in human numbers.
du -sh folder
How big is this folder, really?
free -h
Memory in use.
lsblk
Every drive and partition, as a tree.
nvidia-smi
GPU status, temperature, and what's using it.
htop
Live view of what's running. q to quit.

Reaching Solar Grove

ping -c 3 host
Can I reach it at all? Three tries, then stop.
ip a
This machine's network addresses.
tailscale status
Who's on the tailnet, and are they awake.
ssh user@host
Open a shell on the server.
scp -r src user@host:/path
Copy files over. -r for folders.

Permission & ownership

sudo command
Run as administrator. Asks for your password; nothing appears as you type — that's normal.
chmod +x file
Mark a file as runnable.
sudo chown user:group file
Change who owns it.
whoami · groups
Who am I, and what am I allowed into.

Searching

grep -n "text" file
Find text in a file, with line numbers.
grep -ri "text" folder
Search a whole folder, ignoring case.
find . -name "*.txt"
Find files by name from here down.
command | grep "text"
The pipe | feeds one command's output into another.

Terminal survival

Ctrl+Shift+C / Ctrl+Shift+V
Copy / paste in the terminal. Plain Ctrl+C means something else here.
Ctrl+C
Stop whatever is running right now.
Tab
Autocomplete. Press it constantly — it prevents typos.
↑ / ↓
Scroll back through commands you've already run.
clear
Wipe the screen clean.
man command
The manual for anything. q to leave.
command --help
The short version, when the manual is too much.

Hyprland keys

SUPER + Q
New terminal.
SUPER + R
App launcher.
SUPER + C
Close the focused window.
SUPER + V
Float a window — makes it draggable like a normal one.
SUPER + drag
Left-drag moves · right-drag resizes.
SUPER + 1…9
Jump between workspaces.
SUPER + M
Exit Hyprland.
hyprctl reload
Apply config changes without logging out.
